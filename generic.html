Nyctophobia

Role: Level Programmer - 2026

Nyctophobia is a horror game set in a confined elevator where the player is asked to complete given tasks before the monster catches them. I was the lead programmer for this project, and I designed the base logic infrastructure for the other programmers to build upon. I also designed most of the tasks in the game utilizing interfaces and events to create a modular and extensible system. I created an interactive loading screen that allows the player to interact with it while the next level is loading in the background. A modular task system was implemented, allowing us to select which tasks we want to spawn in each level.

Tidy Tides

Role: Level Design, Programmer - 2024

Tidy Tides is a game designed to promote ocean cleanliness by collecting and recycling trash. We have introduced an NPC who guides the player through the basics, and I have created an inventory system that can store items and drop them when needed. There are two types of items: trash and consumables, which restore health and oxygen. To add some constraints, we introduced a timer, requiring the player to collect the trash before it runs out. If the player fails, a shark will spawn, and upon collision, a turn-based combat system is triggered. When the player recycles the trash, they receive coins, which can be used at the shop to buy consumables.

Bumper Cars

Role: Game Programmer, Network Programmer - 2025

This is a mini scale local multiplayer game made completely on SFML. I have implemented a TCP based client-server architecture for the network connection and implemented UDP for the actual game data transfer to minimize latency. As for latency mitigation, I have implemented a simple linear interpolation for the movement and rotation of the cars. This project was made as a submission for a module in my university.
